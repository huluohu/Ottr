## 🚀 更新内容

### 🔒 安全（P0）
- vault 密封写入方不再先取密钥后拿连接锁——TOCTOU 竞态可在主密码升级提交
  后用旧钥写入密文导致永久不可解（5 处写入路径顺序全部交换）
- SSH exec 输出加 10MB 上限——此前无界累积可在批量并发场景 OOM

### 🛠 修复（P0+P1）
- FTP 传输 EOF 不再静默当成功——校验 `pos==total`，远端截短时显式报错
  （上传下载双向）
- SFTP 补读循环加防御——服务器超量返回时显式报错，不再切片越界 panic
- 同步导入补输入校验——hosts 端口/名称/地址、cron 脚本长度、告警
  rate_limit 不再绕过 create 路径校验直接入库
- 敲 `exit` 退出 shell 不再被静默重连——与意外断线区分，前端不重连
- cron-runs sidecar 输出文件 7 天自动清理——磁盘不再无界增长
- macOS 菜单通知未读数修复——原实现绑定了从未挂进菜单的孤儿实例
- OLED 主题修复从未生效——:root 派生式后置覆盖了显式值，现已后置覆写
- 文件面板右键菜单加视口钳位——不再被裁出视口
- 文件行键盘可达——tabIndex + Enter 打开 / 空格选中
- 设置保存失败在向导外也可见——此前只在升级向导内渲染
- 解锁后补查密钥模式——此前启动时 status 查询失败后解锁不更新 mode
- `files.downloadToLocal` i18n 键缺失修复（裸露键名）
- MCP 主机授权行勾选文字不再竖排
- 告警渠道「启用」开关恢复正常宽度
- AI Provider 列表重排为卡片式行布局
- 降级向导失败保留密码输入（与升级向导口径对齐）

### ✨ 改进（P2）
- 缓动关键字 `ease` 字面值 20 处统一为 motion token
- `--bg-terminal` 死 fallback 移除
- 贴靠选择器弹层 z-index 引用全局令牌
- overview-card 补键盘焦点环 + 空格键激活

macOS / Windows / Linux 三端同步。

## 📦 平台提示
- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
