## ✨ 1.5.1：本地终端全面接通 + 分屏升级 + 本机告警规则

- **本地终端的子页签全部可用**：文件面板双栏都能浏览本机文件（两侧默认目录一致，
  可像远端一样新建/重命名/删除，两栏互拖即复制）；进程面板列出本机进程并可结束；
  监控页签实时显示本机 CPU / 内存 / 磁盘 / 负载 / 网络；总览页新增「本机」卡片。
  分屏不再报错——本地标签分屏就是再开一个本机终端。
- **本机命令历史与会话纪要**：本地终端敲过的命令现在会保存，⌘R 历史面板新增
  「本机」筛选，重启后仍可搜索；会话纪要照常生成。
- **本地终端首屏永远干净**：不再向 shell 逐行敲入集成命令——bash / zsh / sh 全部
  改为通过启动文件加载（先原样加载你自己的配置，再挂接集成），无回显竞速、
  不进历史、无任何残留。Windows 上本地终端改用 PowerShell，并修复了此前
  无法启动的问题；进程面板在 Windows 也可用。
- **本机告警规则**：告警规则的目标新增「本机」——磁盘 / CPU / 进程消失 /
  日志关键字四类规则都能盯本机（需保持一个本地终端标签开启）。本机规则属于
  当前设备，不随配置同步到其他设备。
- **分屏体验**：分屏窗格之间有了浅浅的分割线（拖拽调比例不变）；每个标签最多
  4 块分屏（2×2），到顶后按钮置灰并提示；空间不够再分时会提示，避免分出
  挤不下的窄条。
- **修复**：多个同主机页签来回切换后，终端提示符不再变成一列竖排（此前布局
  过渡瞬间的极窄尺寸会被下发给远端）；托盘「断开全部连接」现在也会断开本地
  终端；本地终端不再出现「双击主机可发起连接」的无意义提示；本地会话不再
  弹「sudo 自动填充不可用」警告。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
