## 🛠 1.7.5：界面层级与布局修复集

上一版（1.7.4）是 22 项功能修复，这一版是一次界面层级专项体检的结果——修的都是「看起来坏掉了」的问题。

### 切换到文件 / 进程 / 监控视图不再变成半屏

切到这几个视图后，主区上半屏曾是一片死空白、面板被压在下半截。原因是这四个面板被渲染到了主区容器之外，导致「终端行折叠让位」的规则失效。现在面板回到正确位置，满幅铺满。

### 面板说明文字不再压在标签栏上

监控视图的「主机资源采样趋势……」这行说明，此前会盖在标签栏与工具行之间。现在它落在工具行下方、面板上方。

### 工具行的切换钮恢复可用

- 右键菜单打开时，点「终端 / 文件 / 进程 / 监控 / 插件」**第一次点击就会切换**（此前第一次只把菜单关掉，要点第二次）。
- 打开设置等对话框时，顶栏会被遮罩正常盖住（此前顶栏仍可点击，一点就把对话框顶掉）。
- 开着「问 Ottr」面板时把窗口收窄，五个切换钮仍在可视区内（此前要横向拖才能看到）。

### 其它修复

- **通知中心**：通知列表恢复独立滚动（此前整页跟着滚，列表区的高度规则因父容器不是 flex 容器而静默失效）。
- **录制列表**：行尾「在访达中显示 / 删除」按钮此前看不见却点得中（会误弹出访达或删除确认），现在不可见即不可点。
- **切换视图不再惊动远端 shell**：此前每次在终端与文件/进程视图间往返，终端尺寸会突变并向远端发一次多余的窗口尺寸信号——跑着 `top`、`vim` 时会重绘、列数变化。现在终端渲染盒保持不变。
- **自动锁定时按 Esc**：此前锁屏出现后按 Esc 会把底下开着的设置页关掉、锁屏纹丝不动，像 Esc 失灵。现在锁屏在场时 Esc 什么都不做。
- **焦点层级**：自动锁定瞬间若还有搜索面板开着，键盘焦点会锁进那个被锁屏盖住的看不见的面板（Tab 在暗处打转、密码框拿不到焦点）。现在按实际层级取最上层。
- **「发现新版本」面板**：补上模态语义，键盘用户能正常 Tab 到「下载并安装 / 重启」。
- **侧栏宽度**：窗口变窄时侧栏自动让位（此前侧栏拖宽后再缩窗，主区会被挤成一条约 100 像素的细条，标签栏与工具栏全被压没）。
- **文件面板**：远端栏标题里的长主机名过长时不再压到相邻栏。
- **ⓘ 说明气泡**：不再盖住同一行的开关并吃掉点击。
- **库加载失败提示**：AI 面板开着时不再被拉成一条几百像素宽的竖条。

### 自动检查更新的两个小修

- **启动时读设置失败不再永久静默**：此前读一次设置失败就当作「没开自动检查」，且不会重试——一次瞬时失败就让自动检查在整个应用生命周期内消失。现在会按退避重试、仍失败则定期重读，读到就恢复。
- 检查的 30 秒超时计时器现在会回收，不再每次检查漏一个。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
