## 🚀 更新内容

### ✨ 新功能
- **AI Provider 支持启用/禁用**：设置 → AI 中每个 Provider 行首新增开关。禁用后该 Provider 不再参与命令诊断、自然语言转命令、会话纪要；默认位被禁用时自动改用下一个可用的 Provider，无需调整顺序。
- **侧栏分组可折叠**：左侧主机列表的分组标题现在可以点击折叠/展开，收起时显示组内主机数；折叠状态跨重启记忆。
- **锁屏小水獭**：锁定屏新增小水獭形象动画——探头、眨眼、扒着门沿等你输入主密码；密码输错会缩一下脖子，解锁时满眼期待。

### 🐞 问题修复
- 正在下载更新时再次点「检查更新」，现在会显示当前下载进度，而不是没有任何反应。
- 关闭所有终端标签页后回到欢迎首屏；此前会停留在总览页或「已选中主机」占位页。
- 总览页改为标签页呈现：打开后固定显示在标签栏第一位，切换会话直接点标签即可，不再需要「← 终端」返回按钮。

## 📦 平台提示
- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
