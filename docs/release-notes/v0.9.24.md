## 🚀 更新内容

### 🛠 界面修复
- 双击终端标签条空白处现在会放大/还原窗口，按住空白处也能拖动窗口
  （此前该区域的双击和拖拽都无效；左侧主机列表栏顶部不受影响）
- 文件列表选中行的高亮不再被鼠标悬停盖掉（此前选中后光标停在上面反而
  看不出选中，移开才显形）
- 帮助菜单点「命令面板」不再一闪而过
- 进程列表兼容 NAS/嵌入式设备的精简 ps：此前部分主机（如 QNAP/Synology）
  连上后进程卡恒为空，现在可正常列出（精简形态下 CPU/内存/时长列留空）
- 「立即重启」按钮改为次级样式，不再与「检查更新」抢视觉

### ✨ 体验改进
- 「总览」从工具菜单迁到「视图」菜单首项，⌘K 命令面板与菜单里也排在
  工具组第一位（主区视图归位）
- 设置页开关的点击命中范围收窄到开关本身（此前点击同一行任意位置都会
  触发）
- 同步页的服务器地址、远端路径、账号、密码输入框加长并对齐（共用同一
  左缘、占满整行）
- 关于页加入品牌 Slogan（如獭穿行于服务器之间。/ Swim through your servers.），
  仓库链接显示补全 https:// 前缀

### 🔒 安全
- 升级主密码遇到无法解密的数据时，错误信息会指明具体的表、字段与行号，
  并明确「升级已回滚、数据未动、可重试」，不再只显示 crypto error:
  aead::Error

macOS / Windows / Linux 三端同步（「总览」菜单项迁移影响 macOS 菜单栏
与各端命令面板/菜单排序）。

## 📦 平台提示
- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
