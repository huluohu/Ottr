## 🖥️ 1.4.10：Windows 托盘菜单修复 + 终端配色可读性

- **Windows：系统托盘图标右键现在能正常弹出功能菜单**（显示主窗 / 断开全部 /
  新建主机 / ⌘K 面板 / 退出等）；左键行为不变（点击切换主窗显示）。此前右键
  在部分 Windows 环境下没有反应。
- **终端低对比颜色自动提亮**：`ls` 的目录蓝、远端 `LS_COLORS` 配出的深色前景等，
  此前在某些主题/服务器配色组合下很难看清。现在终端渲染时会逐字符把前景色
  动态调整到对背景 ≥ 4.5:1（WCAG AA）——内置九套主题、导入的主题、服务器发来
  的任意配色组合全部覆盖，无需逐主题调色。
  小取舍：个别刻意压暗的「暗淡」输出（如部分进度条）会比以前略亮，可读性优先。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
