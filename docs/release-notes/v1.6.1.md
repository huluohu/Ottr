## 🚀 1.6.1：TOTP / 2FA 交互式登录 + 系统 SSH-Agent 桥接 + Ask Ottr 与外部 MCP 客户端集成

- **TOTP 生成器与 keyboard-interactive 交互式认证**：
  - 零新增第三方依赖实现 RFC 6238 标准 TOTP 生成器，支持配置验证码位数（5~10 位）与时间步长（兼容 Steam、Azure、各类自建 2FA 设施）；
  - 全链路打通二次认证跳板机与 PAM 挑战应答：智能识别动态验证码提问并预填，配备毫秒级倒计时与到期自动平滑换码机制，无感登入双因子保护服务器。
- **系统 SSH-Agent 桥接（私钥零落地）**：
  - 新增「系统 ssh-agent」凭据类型，原生对接 macOS / Linux 系统运行中的 SSH-Agent（如 1Password、系统 ssh-agent、钥匙串代理桥）；
  - 借助 russh 外部签名器完成公钥认证：私钥物理留存于系统 Agent 进程内，Ottr 内存与磁盘不存留任何私钥材料，多身份密钥智能逐项探测尝试。
- **Ask Ottr 智能上下文问答中枢**：
  - 终端工具行增设显式「问 Ottr」操作按钮与全局快捷键（`⌘⇧A` / `Ctrl+Shift+A`，`⌘K` 调色板同步收录）；
  - 面板主动提问自动附带当前聚焦会话的最近 8KB 终端输出上下文与主机运维备忘，开箱即懂当前现场，精准定位排障。
- **多轮会话追问、Markdown 渲染与成本透明化**：
  - 诊断与提问面板全面升级为多轮气泡对话流，底部配备自适应多行输入框（支持 Shift+Enter 换行）；
  - 采用无 XSS 隐患的纯净 Markdown 排版引擎，支持表格内容级横向滚动、列表及安全隔离代码块一键插入终端；
  - 实时呈现本次对话生效模型名称、输入/输出 Token 精确统计与响应耗时，用量账目清晰透明。
- **外部 MCP 客户端与 AI 工具调用闭环**：
  - 支持配置外部标准 MCP Server（stdio 协议流通道、环境变量 AES-256-GCM 密文封存、沙箱环境变量最小化）；
  - 支持在设置中即时浏览外部工具目录与参数表单调用测试；
  - 接入 AI 工具调用闭环：模型发起工具调用时生成待执行确认卡片，坚守「用户点击确认后方可执行」的安全铁律，调用结果安全脱敏后回填模型继续推理。
- **已知主机（known_hosts）批量导入与安全加固**：
  - 支持从本机 `~/.ssh/known_hosts` 一键导入信任锚点（智能解析自由注释列、端点优先采用 ed25519 高强度算法）；
  - 施加绝对路径限制、常规文件校验、符号链接防护、文件大小与条目规模硬上限防 DoS。
- **全面安全与跨平台健壮性加固**：
  - 废除本地私钥落盘机制，解决 Windows 平台临时目录文件 ACL 继承风险；
  - 扩充脱敏引擎至 11 大类敏感规则，严密拦截中文密码、环境变量机密、Shadow 哈希与私钥块，助手历史回复脱敏再出网；
  - 收窄 HTTP 出网能力门禁，默认仅放行本地明文 HTTP，远端强制 HTTPS 并显式阻断内网元数据探测；
  - 8KB 终端截断字符安全退避，杜绝多字节 UTF-8 乱码；长语言国际化排版自适应折行。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
