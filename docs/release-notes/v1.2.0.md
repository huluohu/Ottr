## 🎨 1.2.0：主题家族扩容 + 繁體中文

这一版把外观与语言两件「用得舒服」的事做足：主题从七套扩到十套（补齐暖调
亮色、森林暗色、暖光暗色三个方向），语言新增繁體中文——界面、macOS 原生
菜单、托盘三处完全对等。同时按使用方式重新划定了功能入口的位置：会话里的
能力跟着会话走，全局能力常驻全局入口。

### 🌊 三个新主题（水域家族续编）

- **沙洲**：暖纸色亮色主题——奶油暖白底、褐色墨、琥珀主色，纸面阅读感，
  长时间盯屏更柔和
- **松涛**：深松绿暗色主题——近黑的松绿底、翡翠绿主色，冷调护眼
- **河灯**：暖光暗色主题——河畔夜褐底、灯火琥珀主色，暖色界面配冷青点缀，
  与现有暗色主题一眼区分
- 全部主题的界面配色与终端配色都按对比度标准（WCAG）逐色校准过；
  设置 → 外观 或 Otty 球 → 主题 即点即换

### 🌐 繁體中文

- 新增**繁體中文**语言（港澳台通用词汇）：界面、macOS 原生菜单栏、托盘、
  通知文案全部繁体，与简体功能完全对等
- 系统语言为繁体中文（台湾/香港/澳门）时首次启动自动选用
- Otty 球 → 语言、设置 → 通用、⌘K 三处均可切换；切换即生效、跨设备同步
- 繁体模式下终端字体自动换用繁体字形优先的字体栈

### 🧭 入口重新划界：会话的归会话，全局的归全局

- **视图切换器跟随会话页签**：终端/文件/进程/监控/插件这组切换器只在
  会话页签语境出现——切到通知中心、定时任务等页面时整组隐藏，不再出现
  「点了对当前页面无意义」的按钮
- **录制按钮同规则**：只在会话语境显示；正在录制时切到任何页面都会保留
  红色指示与停止入口，不会悄悄录
- **工具菜单瘦身**：监控/插件移出工具菜单（它们在会话切换器里）；工具
  菜单只剩全局功能
- **历史/回放入口更好找了**：历史命令、会话纪要、录制回放与导出搬进
  Otty 球菜单（此前只能靠 ⌘R 呼出，很多用户不知道这些功能存在）
- **⌘K 命令面板重整**：去掉重复条目与「打开命令面板」自身；「退出」不再
  出现在搜索结果里（防误触，菜单/托盘仍可达）；主题与语言从「循环切换」
  改为逐项列出、点哪个换哪个

### 🔧 其他改进与修正

- **文件列表在窄窗口不再挤没文件名**：面板较窄时依次收起权限、时间等
  次要列，文件名任何宽度下都完整可见（宽面板仍显示全部四列）
- **打开监控/插件不再没反应**：未连接主机时给出「先连接主机」提示
- **锁定状态不再报「数据加载失败」**：锁定是正常状态，锁屏本身已说明一切；
  真正的加载失败仍会照常提示
- **⌘\ 折叠主机面板进菜单**：macOS 视图菜单新增此项（此前只能盲按快捷键）
- **Ctrl+Tab / Ctrl+Shift+Tab 切换会话标签**（终端内输入不受影响）
- **默认窗口更大**：800×600 → 1280×832，高分屏上不再局促
- **终端在异常重排时不再出现竖排乱字**：连接失败关标签后其他终端字体
  塌缩成 1 列竖排的问题已在根因上加固
- **主题持久化修复**：上一批新主题在「同步 + 重启」场景下会被旧版本的兼容校验
  拒绝而丢失——已修复，并重构为主题注册表单源（新增主题的十处接线收敛
  为一处，杜绝同类遗漏）
- **录制按钮间距**、**宽幅视图满宽**、**空态居中**等一批视觉细节修正

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
