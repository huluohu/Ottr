## ✨ 1.3.0：NAS 默认 shell 也能自动诊断了

- **sh 系远端自动诊断**：连接 busybox ash / dash（NAS 固件与 Debian 系常见的
  默认 `sh`）时，应用现在会自动向远端 shell 注入轻量集成——命令失败（退出码
  ≠0）照常弹出 AI 诊断面板，不再要求远端装 bash/zsh。此前这类会话里失败命令
  （如 `xxx: command not found`）不会触发面板。
- **注入失败零残留**：sh 集成带验证-回退护栏——下发后若确认远端 shell 不支持
  （标记未在窗口内出现），自动恢复原提示符，会话状态与注入前完全一致；哪怕
  片段因语法差异解析失败，回显也独立恢复，不会出现「终端不回显」的后遗。
  fish / nushell 等仍未支持，保持跳过不注入。
- **边界说明**：sh 系会话的 AI 诊断可用，但 ⌘R 命令历史与输入补全仍要求
  bash/zsh（sh 无法上报可靠的命令边界文本，宁缺勿滥）。面板顶部显示的命令行
  在 sh 会话里可能显示为最后一条输出而非命令本身，退出码与输出内容不受影响。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
