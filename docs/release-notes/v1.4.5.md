## ✨ 1.4.5：主机管理更顺手，界面更克制

- **主机列表支持右键菜单**：在左侧主机上点右键，可直接「编辑主机」或
  「删除主机」——删除仍需二次确认（行内确认），不会误删；Esc 或点空白关闭。
- **打开主机默认进终端**：在文件、进程、监控、插件任一视图里双击另一台
  主机，会切回终端面开始使用，不再停留在原来的视图。
- **FTP / FTPS 会话界面收口**：这类协议只支持文件传输，工具行里不再出现
  无意义的分屏按钮和字符集按钮，只保留「文件」视图。
- **子页签不再显示「开始录制」**：录制内容始终是这条会话的终端输出，与你
  当时在文件/进程等页签里的操作无关——现在这些页签不再提供开始入口，避免
  误解；若录制已经在进行，切到这些页签仍保留「录制中」红点与停止按钮。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
