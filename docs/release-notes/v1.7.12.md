## 🛠 1.7.12：数据安全、输入正确性与流畅度的一次全面体检

一次覆盖全项目的系统性检查，共修 40 余项，多数是平时不容易撞上、但撞上就会误操作或卡住的毛病。

### 数据安全

- **文件列表可能对不上目录**：快速连续点不同目录时，慢的那次返回可能后到，把列表覆盖成上一个目录的内容——此时路径栏写着 B、列表却是 A 的条目，按路径栏选中、删除、下载作用的都是**另一个目录里的同名文件**。现在迟到的返回会被丢弃，列表始终与路径栏一致。
- **跳板链删除会波及主机**：删除跳板链会自动解除引用它的主机绑定。现在删除前会说明「引用它的主机将解除绑定，此操作不可撤销」，并需要二次确认。
- **破坏性操作补二次确认**：定时任务删除、通知「清空」、告警渠道删除此前一点即删（通知清空不可恢复）。现在四处都先确认，文案说明后果。
- **导入文件加大小上限**：导入主机清单或 SSH 配置时，误选一个超大文件会让应用长时间卡住不动。现在超出合理大小的文件会被明确拒绝。
- **导出主机 CSV 不再丢信息**：CSV 往返此前只带 8 列，**FTP/FTPS 主机重新导入后会变成 SSH**，「监控面板」开关与「生产环境」标记也归零。现在导出 11 列，这三项原样保留；旧版 8 列的 CSV 仍可导入。

### 输入正确性

- **中文/日文/韩文输入法用户按回车会直接连主机**：在命令面板里用输入法搜主机时，上屏候选词按下的回车会被当成「执行当前选中项」，选中项恰好是某台主机时就直接发起连接。现在输入法组字期间（候选词还在选的时候）回车与方向键一律放行给输入法。
- **一次 Esc 关掉两层**：搜索栏开着时又弹出对话框，按一次 Esc 会把两层一起关掉；最坏的情况是把主机密钥的安全确认一起拒掉，连接莫名失败。现在 Esc 只关闭最上面那一层。
- **⌘F / Ctrl+F 不再抢键**：在对话框开着、或在输入框里打字时按它，不再弹出终端搜索框。
- **快捷键改绑在 Windows/Linux 上会「看起来保存成功、实际不生效」**：系统默认键位把它遮住了，且没有任何冲突提示。现在冲突能正确报出来。

### 稳定性与资源

- **命令超时后远端不再留悬挂进程**：定时任务、监控采样、批量执行在超时时，此前会直接丢弃执行句柄——远端的命令继续跑着，SSH 通道也不回收，反复超时会越积越多。现在超时会显式关闭通道并终止远端命令。
- **托盘菜单「断开全部连接」现在真的断开**：macOS 上这条此前点击零效果；三个平台共通的问题是它只断开终端会话，**FTP/FTPS 文件会话仍保持连接**（机器上留着活动凭据）。现在三张会话表统一收尾。
- **zsh 用户：终端的当前目录锚点一直取不到**：提示符里的 `\` 被当成了变量转义，导致目录跳转、历史入库与 AI 的目录上下文全部失效。已修正。
- **窗口尺寸记忆**：最大化状态下退出，重启后取消最大化，窗口会回落到系统默认大小而不是你上次用的尺寸。现在回落到你上次用的尺寸。

### 流畅度

- **AI 回答流式输出不再卡**：此前每收到一小段就把已收到的全文重新脱敏、重新排版，长回答会明显卡顿。现在按固定节奏合并刷新，主线程占用降约一个数量级。
- **大目录拖文件不再拖不动**：排序和渲染每次指针移动都重做一遍，几千个条目的目录会拖不动。现在排序结果缓存、拖拽浮标不再触发整面板重绘。
- **终端读屏模式改为设置项（默认关）**：2026-11 起终端支持读屏软件（NVDA/VoiceOver），但此前是对所有用户无条件常开——这在终端输出刷屏时相当吃 CPU（实测可占掉半个到一个核，风扇转、笔记本掉电）。现在改为**设置 → 外观 → 终端读屏模式**里的开关，默认关闭；使用读屏软件的用户打开一次即可。
- **设置页不再偷跑请求**：切到别的分区时，告警/AI/MCP 三个分区会在后台悄悄跑数据请求。现在只在切到该分区时才加载。
- **同步设置不再吞草稿**：改了另一个通道的配置再去保存别的通道，草稿会被悄悄吞掉、切分区也会被重置。现在保留。
- **AI 历史轮的命令重新能插进终端了**：某一轮出错或被中断后，此前所有历史轮的插入按钮都灰死，且理由文案并不成立。现在只禁正在生成的那一轮。

## 验证情况

- 自动化测试：前端全量 176 个测试文件、2145 个用例；Rust 侧工作区全部用例。类型检查无错，静态检查零告警。
- 本次新增 5 条针对性检查（输入法组字期间回车与方向键放行 4 条、文件列表导航竞态 1 条、弹窗在场时图标轨浮层收起 1 条），每条都做了「摘掉修复 → 检查必须变红 → 还原 → 全绿」的来回验证。
- **真机验证（Ubuntu 24.04，WebKitGTK）**：跳板链删除 / 通知清空 / 告警渠道删除三处二次确认，逐处确认「点删除 → 出现确认 → 数据仍在 → 点确认 → 真删除」；Esc 逐层关闭（下层搜索栏不被误关）；窗口尺寸记忆与最大化还原的完整路径；读屏开关的存在与切换。另有 **Linux 平台**的 Rust 与前端全量测试各跑一遍。
- 未覆盖（逐条说明原因）：输入法组字的真机实测（该平台输入法吞中文，造不出组字状态，改由合成事件钉住该分支）；文件列表导航竞态的真机实测（本地文件栏是同步读取、天然无竞态，远端栏需要真实服务器与慢链路，改由延迟模拟钉住）；读屏模式的**实际朗读效果**（该平台的 WebView 未暴露无障碍文本层）；macOS 上托盘与 Dock 菜单的点击效果、Windows 上的窗口行为——均需对应平台的机器验证。
- 本版本不含数据库迁移，无需手动升级操作。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」。便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
