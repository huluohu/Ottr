## 🎉 1.0.0：让整条河活起来

第一个正式大版本。这一版把「水」流进了界面的每一条缝隙——新图标、新主题名、新布局骨架和水感动效，功能行为与 0.9.x 完全兼容，升级后无需任何迁移操作。

### ✨ 界面焕新

- **全新应用图标**：几何化的小水獭标识，16px 大小的 Dock/任务栏/托盘里依然清晰可辨；原来的仰漂水獭插画保留在欢迎页等大尺寸场景
- **48px 图标轨**：总览、文件、定时任务、告警、通知中心五个高频入口常驻窗口左侧，未读数直接挂在图标上；面板打开时对应图标会亮起常驻光点，弹框开到哪一眼可见
- **Otty 球控制中心**：窗口左下角的水獭圆钮收纳凭据、MCP、主题、语言、设置——原先藏在折叠菜单里的入口现在一键直达
- **主机面板可折叠**：`⌘\`（Windows/Linux 为 `Ctrl+Shift+\`）把主机列表折成 64px 悬浮胶囊，只留搜索钮、分组色点和未读提示，再按一次展开
- **主区去框化**：终端主区去掉内层描边，靠底色深浅分区，视觉更静

### 🎨 主题「水域家族」

七套主题全部换上成体系的新名字，并按光亮程度排序（跟随系统恒居首位）：

| 新名 | 原名 | 意象 |
|---|---|---|
| 浅滩 Shallows | 亮色 | 暖纸白，獭宝宝嬉水处 |
| 溪岸 Riverside | 青野 | 鼠尾草绿，水獭生活的河岸 |
| 深河 Deep Water | 暗色 | 深水背景基调 |
| 深渊 Abyss | 曜黑 | 纯黑无光层（OLED） |
| 夜光河 Bio River | 幻紫 | 生物荧光的夜河 |
| 雨窗 Rain Glass | 雾镜 | 真透明毛玻璃 |

主题选择处保留旧名对照提示（至 2027 年 1 月），设置页的主题卡网格同步新名与新排序。

### 🌊 水感动效

- **悬浮岛页签**：每条会话是一根浮木——圆角小岛浮在水面，激活岛青色描边微微升起
- **状态点水滴语言**：连接中呼吸缩放、连接成功弹跳落定、断开时涟漪扩散渐隐；主机列表行与总览卡同步这套语言
- **涟漪按压反馈**：主按钮与列表行的按下水波纹，圆心跟随真实触点
- **Otty 情感时刻**：连接成功时小水獭从角落探头划水、传输完成星光滑过、解锁时草叶飘落、更新就绪冲浪板滑过顶沿——同一时刻最多一只水獭在场；不喜欢可以在 设置 → 外观 一键关掉

### 🖼 主机行状态点

主机列表每一行现在自带连接状态点：青色 = 已连接、琥珀色呼吸 = 连接中、空心 = 离线——不用开标签也能看到谁在线。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
