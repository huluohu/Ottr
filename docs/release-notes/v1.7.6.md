## 🛠 1.7.6：发布质量保障闸门（应用本体与 1.7.5 一致）

这个版本**没有任何应用功能或界面变化**——变化在开发侧：把「全视图布局自动检查」接入合并门，是 1.7.4 / 1.7.5 两批界面问题的防复发措施之一。

**给用户的建议**：

- 已经在用 **1.7.5** 的：可以跳过这个版本，直接等下一个功能版本。
- 从 **1.7.4 或更早**升级的：直接装 1.7.6 即可（等同于 1.7.5 的全部修复 + 本闸门）。

**这次接入了什么**：应用的全部 13 个界面视图（终端、文件、进程、监控、插件、总览、定时任务、通知中心、端口转发、跳板链、AI 面板在场、设置对话框等）现在会在每次合并前被无头浏览器逐个打开并自动检查几何关系——面板是否铺满、切换按钮是否可点、模态是否盖住顶栏、有无横向溢出。此前「切到某个视图面板只剩半屏」这类问题（1.7.4 用户实报）单测测不到、真机走查也可能看走眼，现在这类回归会在合并前被自动拦下。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
