## 🚀 1.6.5：「问 Ottr」精灵球入口 + 多主机严格隔离

- **「问 Ottr」精灵球**：终端区域新增一个可拖动的 Otty 悬浮球，点击即打开提问面板。
  - 外观沿用现有品牌标识（呆毛歪头的青绿獭头），不是外来的吉祥物；
  - 可拖到窗口内任意边缘停放，位置只在本机记住；设置 → 外观可一键关掉或重置位置；
  - 关闭只隐藏这个入口，**不影响**提问功能、工具栏按钮与快捷键；动画装饰在场或弹出对话框时它会自动让位。
- **多台主机之间的严格隔离**：A 终端的上下文、回答与命令不会再跑到 B 终端去。
  - 每台主机、每个分屏、每条连接（含重连后的新连接）各自独立保存对话与草稿；
  - 在 A 终端提问后切到 B，面板显示 B 自己的对话，切回 A 则完整恢复 A 的对话；
  - 连接断开重开时，旧对话保留供查看但标记为只读，新连接从新对话开始，旧命令不会改投到新连接；
  - 面板标题显示当前问答的对象（主机、账户、地址、连接状态），生产环境主机另有标记。
- **命令插入力度收紧**：AI 生成的命令只插入**生成它的那台终端**，绝不悄悄改投当前窗口；
  焦点不在原终端时插入按钮禁用，并提供「回到原终端」一键切回。命令仍然只插入、不自动执行、不代按回车。
- **工具调用提示**：面板会说明外部工具在 MCP 服务器侧执行、不受本终端范围约束，每次执行仍需你确认。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
