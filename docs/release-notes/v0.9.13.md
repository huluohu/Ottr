## 🚀 更新内容

### ✨ 新功能
- macOS 窗口标题栏融入应用界面：内容延伸到窗口顶部，红绿灯按钮悬浮于侧栏上方
  （与常见桌面应用一致的沉浸式观感）；侧栏顶部与终端标签条空白处均可拖动窗口

### ✨ 体验改进
- 设置页页签重排：「通用」排第一，打开设置默认落在通用区
- 全局弹窗行为统一：同一时间只显示一个弹窗，打开新弹窗时先关闭已打开的弹窗，
  不再出现面板与对话框层层叠放

### 🐞 问题修复
- 工具菜单混入设置类条目的问题修复：移除「MCP」与「同步」两项（MCP 统一从
  设置 → MCP 分区进入；同步统一从 设置 → 同步 分区的「立即同步」发起）——
  工具菜单现在只保留功能面板与主机工具

## 📦 平台提示
- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
