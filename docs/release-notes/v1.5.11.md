## 🔄 1.5.11：终端里按回车就能继续重连

- **断线后按回车即重连**：自动重连 5 次都没成功、终端停在「自动重连 5 次未成功，已停止」时，光标还在终端里——按回车就重新开始重试（1 秒、2 秒、4 秒、8 秒、16 秒逐步退避，从第 1/5 次重新起步）。服务器恢复后自动接上，不用回左侧双击主机。
- **上次留下的标签也能用回车连接**：此前按回车没有反应，现在回车即连。
- **连接时终端更干净**：为识别命令边界而加载的终端增强，不再往屏幕上写任何一行内容——精简系统（没有 stty 的环境）和 zsh 上尤其明显，以往会看到一行看不懂的字符。
- **你自己的提示符脚本照旧生效**：写在 `PROMPT_COMMAND` / `precmd` / `preexec` / `DEBUG` trap 里的内容不会被顶掉，命令的原始退出码也照常传给它们。
- **Ctrl+C 撤销的失败不再弹 AI 诊断**：误粘贴后按 Ctrl+C 撤销掉的失败，不再被当成需要诊断的故障。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
