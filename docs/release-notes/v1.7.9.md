## 🛠 1.7.9：命令诊断面板的消息排版修正

修「命令诊断」面板里消息显示的排版逻辑，外加补一个此前没有的入口。

### 体验类

- **面板里的指示一会儿在上方、一会儿在下方**：这个面板此前分三段——顶部固定着「停止」「思考中…」「已取消」和出错提示，中间是会自己滚动的对话区，底部是执行方式下拉和追问输入框。问题出在「正在发生的事」和「已经发生的事」被拆到了两处：**正在发生的指示钉在顶部，真正在进行的对话在下面那块自己滚动的区域**。于是模型一开始输出，指示就从顶部跳到对话末尾；对话一长，**「停止」还会被顶出可视区，想停都点不着**。
  现在一条规则：**对话在上，正在发生的状态在中间，输入区在下**——一个固定位置。停止 / 思考中 / 已取消 / 出错提示整体下移到对话末尾、输入框正上方；顶部只留静态信息（失败命令的卡片、本次外发的脱敏计数）。
- **新消息不再落在屏幕外**：这块对话区此前**从不跟随滚动**——长对话里新回复常常落在折线以下，界面看着像「什么都没发生」。现在新消息和正在输出的文字会自动贴到底部；**你手动往上翻看历史时不会抢你的滚动**（翻回去就不拽），窗口尺寸变化后也会重新贴底。
- **补「回到最新」入口**：往上翻了以后没有任何办法快速回到最新消息——只能一路拖回来，或者等新消息把你顶下去。现在你一往上翻，对话区右下角就浮出 **`↓ 回到最新`**：点一下立刻回到底部，并恢复自动跟随。这个按钮是浮动的，**出现和收起都不会挪动任何内容**（初版做成独占一行，往上翻的瞬间它会把对话区压矮约 30px、正在看的内容跟着跳——与本次修的毛病同族，已改掉）。本来就在底部时它不出现。八种语言都已补上。
- **顺带修掉的三处小毛病**：出错时错误卡片下面会多出一条约 28px 的空白死区（一个没有内容的状态行仍占着位）；点「新对话」清空消息后「回到最新」可能悬空残留、点了没反应；一处永远成立的显示条件。

## 验证情况

- 自动化测试：前端全量 176 个测试文件、2128 个用例全部通过（含本次新增 6 条：位置关系、按钮出现与收起、错误态无空行等）。
- 自动布局检查新增一个「正在回答」的形态：要求正在发生的状态不压住对话区、不压住输入区、停止钮必须点得到且在视口内、对话溢出时必须贴底、上翻后「回到最新」必须出现且可点且点了真的回到底、**且按钮出现不得压矮对话区**。20 个界面形态全部通过。
- 这些新检查都做了来回验证：把已发布过的坏写法换回去，检查会精确报红并给出具体数字（例：「『回到最新』出现把对话区压矮了 23px」「往上翻了却没有『回到最新』按钮（回不到最新消息）」），还原后恢复全绿。其中一条检查的**第一版量错了对象**（量的是输入区位置，而坏形态下输入区纹丝不动，注入坏代码后检查照样全绿）——已改为量对话区自身高度并重新验证。
- 未覆盖：**macOS 上的目视确认**（本轮验证在无头浏览器与 Linux 真机完成，未占用 macOS 桌面环境）；**Windows** 平台行为。本版本不含数据库迁移，无需手动升级操作。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」。便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
