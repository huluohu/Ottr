## ⌨️ 1.5.5：快捷键自定义改键

- **设置新增「快捷键」分区**：全部动作都可以自定义快捷键——列表支持搜索，
  点「修改」后按下新组合键即完成改键（Esc 取消）；改过的动作可单独
  「恢复默认」，也可一键「全部恢复默认」。
- **改了就全跟**：命令面板、汉堡菜单、欢迎卡里的快捷键提示，以及 mac 顶部
  菜单的加速器，全部自动跟随你的改键；实际按键即时生效。
- **冲突与误触防护**：与其它动作撞键会被拒绝（并告知撞了哪个动作）；没有
  修饰键的裸字母键不允许改绑（避免输入时误触）；带 ⌘/Ctrl/Alt 或使用
  F1-F24 均可全局生效。
- **改坏了有退路**：覆盖随配置同步到其他设备；「全部恢复默认」一键回出厂，
  设置页纯鼠标可达，改坏任何键都能进设置救回来。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
