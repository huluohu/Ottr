## ✨ 1.4.3：文件传输更顺手，Tab 回归 shell 补全

- **文件面板支持多选与批量传输**：⌘ 点选（Windows / Linux 用 Ctrl）、
  Shift 范围选择；工具栏「下载 (N)」一次把选中的多个文件加入队列，每个
  文件各自显示进度、可单独取消或重试。本地栏新增「上传 (N)」批量上传。
- **文件面板支持拖入整个目录（递归上传）**：把本地文件夹拖到远端栏，或
  在本地栏把目录行拖到远端栏，都会自动在远端建好同名目录树并逐个上传
  文件——不再提示「目录已跳过」。上传过程进入传输队列，可逐个查看进度。
- **终端拖拽目录也会递归上传**：把文件夹拖进终端，使用 trzsz 上传时会
  连同子目录一起传完（需要远端装了 trzsz，与原来拖文件上传一致）。
- **文件面板记住上次的目录**：本地栏和远端栏分别按主机记住你最后所在的
  目录，切到别的视图再回来（或重开面板）不会被打回主目录；记下的目录
  若已不存在会自动退回主目录。
- **Tab 恢复为 shell 原生补全**：终端里按 Tab 现在始终交给 shell 做命令、
  路径、文件名补全，不再把历史命令整条补上；想采用灰色的历史建议，按
  右方向键 →（Esc 忽略）。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
