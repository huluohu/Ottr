## ✨ 1.4.0：诊断面板按会话独立 + 主机与页签体验升级

- **AI 诊断面板按会话独立**：后台主机的命令失败不再抢占当前正在看的会话——
  对应页签亮起琥珀「AI」徽标，切过去即可查看。面板顶部显示所属主机名，
  「插入终端」始终作用于面板所属的会话，多主机并行时不再插错机器。
- **主机列表支持拖拽移动分组**：把主机行拖到目标分组的组头上放下即可，
  立即持久化；拖拽经过时目标分组高亮提示。
- **主机表单不再「够不着按钮」**：表单改为内容区滚动、取消/保存固定在
  底部——展开「新建凭据」子表单后按钮也不会被顶出窗口。
- **页签行重新划界**：会话页签独占一行；「终端 / 文件 / 进程 / 监控 /
  插件」切换与录制按钮移至终端工具行，会话开得再多也不再与右侧常驻
  控件拥挤打架。
- **锁屏背景虚化**：锁定后背景内容模糊不可读，符合隐私与防窥预期。

## 🔧 修复

- **切换页签后输入框冒出提示符碎片**（如 `[h`、`[r`）：根因是宽度变化
  触发远端重绘叠加初始尺寸退化，已从源头消除退化尺寸的上报与下发。
- **终端偶发整列竖排文字**：页签/面板切换瞬间的布局抖动可能把终端压塌
  成极窄并永久重排，现在退化尺寸不再生效（此前长期挂账的「字符乱飞」
  问题的确定性守卫）。
- **macOS sudo 密码提示符缺少冒号**：`Password:` 的冒号在输入密码期间
  不显示、回车后才出现——由内建传输优化误扣提示符尾字符导致，已修复。
- **Ctrl+C 终止的命令不再触发 AI 诊断**：主动取消不是故障（包括在 sudo
  密码提示符处取消）；真实失败照常诊断，命令历史不受影响。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
