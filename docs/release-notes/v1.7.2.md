## 🎯 1.7.2：插话体验打磨 + 设置键盘导航

「问 Ottr」回答中随时插话（1.7.1）按反馈打磨：

- **执行方式改下拉**：输入框正上方的三档页签收进一个下拉框——**逐条确认（默认）** / 自动执行。默认状态下 AI 提出的命令直接以待确认卡出现，点「执行」= 授权这一条，**不再需要先切模式**；「规划」档收起（确认卡本身就是计划）。
- **按钮恒为「发送」**：回答生成中按钮不再变成「打断并插入」——草稿非空时点它就是打断并插话，文案永远是「发送」。
- **自动执行更诚实**：该选项的授权状态在面板打开时就检查——未授权的主机上「自动执行」直接置灰，并常显原因（设置 → AI → 允许自动执行的主机），不再「能点但降级」让人误会。

设置页：

- **侧栏支持键盘导航**：↑/↓ 在分区间移动并切换（焦点即选中），Home/End 跳首尾；Tab 在侧栏只停一次。搜索框内的方向键保持原生光标行为，不抢键。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
