## 🔄 1.5.16：同步误报修复 + 文言界面 + 多项打磨

- **同步不再误报失败**：部分 WebDAV 服务器（如 alist）保存成功后返回的特殊状态码，此前会被误判为「同步失败」——实际文件已经写上云端。现在如实按成功处理。
- **冲突裁定修了一个死角**：本机与云端内容实际一致、只是指纹不同时，裁定面板会变成一排无法操作的死按钮；现在给出明确说明和「重建同步基线」按钮，点一次即恢复。
- **新增文言界面**：语言增加「文言（古语）」，排在繁體中文之后；导航、设置、原生菜单、托盘全局生效。
- **MCP 接入配置更好用了**：配置片段里的程序路径直接填好真实值，不用再自己找路径替换；复制按钮移到代码块右上角；展开配置不再把页面撑乱。
- **告警页的分区切换改成页签样式**：与旁边的操作按钮不再混淆。
- **关于页**：博客地址单独一行，并分别标注「博客」与「项目」。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
