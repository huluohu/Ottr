## ✨ 1.5.0：本地终端 + 页签与主机管理升级 + Windows 托盘菜单再修

- **新增「本地终端」**：不必再 SSH 连 localhost，直接在 Ottr 里打开本机的
  shell。入口在左侧图标栏的「本地终端」按钮，⌘K 面板里搜「本地终端」也能
  打开；可以同时开多个，页签固定排在最前面。bash / zsh 会自动接入与远端
  一致的 shell 集成——⌘R 命令历史搜索可用，且不会在你的 shell 历史里留下
  集成脚本的痕迹；其他 shell 按普通终端使用。
- **本地会话也能录制**：会话录制现在覆盖本地终端，shell 退出（如敲 `exit`）
  时录像自动保存到历史，与远端会话的录像放在一起管理。
- **同一台主机可以多开**：主机右键菜单新增「连接主机」，每点一次都新开一个
  会话页签，方便对同一台机器并行开多个会话；双击主机仍是切到已打开的页签。
- **页签右键菜单**：新增「重命名页签」（在页签上直接改名，只对当前页签有效，
  关闭后不保留）和「复制连接」（把 `user@host:port` 复制到剪贴板，30 秒后
  自动清除）。
- **Windows 托盘菜单再修一次**：1.4.10 的修复在部分 Windows 环境下右键仍然
  不弹菜单。本版改用最通用的做法——托盘图标左键、右键都直接弹出功能菜单，
  要显示主窗点菜单里的「显示主窗」（左键不再是「点击切换主窗显示」）。
  macOS / Linux 的托盘行为不变。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
