## 🛡️ 1.5.19：安全加固 + 全面无障碍与键盘体验优化 + 导入报错八语本地化

- **安全加固**：
  - 公钥部署全面接入主机密钥 TOFU 验证策略，服务端直接解析端点，消除中间人嗅探风险；
  - OpenSSH 格式导出增加控制字符拦截与换行转义，杜绝配置文件指令注入隐患；
  - 定时任务运行日志文件权限收敛为 0600 私有访问，防止多用户环境下日志泄露敏感输出。
- **功能与交互修复**：
  - 修复 Windows 与 Linux 平台下「导出主机」入口无响应的问题；
  - 总览页主机卡片新增「关闭监控」入口，支持一键停止实时采样并同步持久化配置；
  - 修复修改自定义快捷键后 ⌘K 命令面板未实时刷新按键提示的问题；
  - 库级操作错误（如删除主机/凭据失败）在处于终端会话时增加常驻横幅提示，不再静默失效；
  - 终端底层连接失效时，键盘输入增加节流状态提示，明确指出写入失败原因。
- **全局无障碍（a11y）与键盘体验升级**：
  - 全局模态弹窗实现焦点陷阱，键盘 Tab / Shift+Tab 严格在弹窗内循环，关闭后焦点原位归还；
  - ⌘K 命令面板列表全面支持标准语义化标签，读屏工具可流畅识别焦点移动；
  - 终端引擎开启原生读屏模式（VoiceOver / NVDA 可完整朗读终端回显）；
  - 会话标签关闭按钮、总览页卡片动作按钮及分屏窗格关闭按钮全面支持纯键盘操作。
- **国际化（i18n）**：
  - 各种格式（CSV/Xshell/Tabby/SSH Config）的主机导入报错信息全面支持八种语言本地化翻译。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
