## 🌊 1.1.0：信息架构重构——弹框退役

这一版把 v1.0.0 反馈集中的「工具弹框」形态整体退役：所有管理面板按使用方式
重新安家——低频运维工具升为图标轨一级入口 + 主区宽幅视图，会话级能力收进
终端视图的子页签，纯配置归设置页。终端优先的工作方式不变。

### ✨ 图标轨一级入口（主区宽幅视图）

- **定时任务**：从弹框升级为宽幅管理视图——任务列表、运行历史展开、
  编辑表单在主区完整呈现，反复查看运行结果不再 cramped
- **通知中心**：同样升级为宽幅视图，通知列表一目了然
- **端口转发**：状态灯、字节计数、启停操作获得完整操作面
- **跳板链**：多级跳板拓扑的可视化编排获得完整编辑空间
- 以上入口全部常驻图标轨，所在视图互相切换、终端一键回返

### 🖥 会话子页签

终端视图的「终端 / 文件 / 进程」切换扩为五页签：新增**监控**与**插件**——
两者本就是跟随连接的能力（监控采样、会话命令），现在与终端/文件同级直达，
不再需要先连一次主机再从工具菜单绕行。FTP/FTPS 连接自动隐藏这两项。

### ⚙️ 告警归位设置

告警的渠道配置与规则向导整体收进**设置 → 告警**分区（图标轨告警钮一键直达）——
通知渠道本就是跨功能基建（定时任务通知共用），归位后与其他配置同域管理。

### 🔧 其他改进与修正

- **AI 生成命令：插入即执行姿态**——命令插入终端后自动切回终端视图并把
  光标交还终端（文件 / 进程页签下同样生效），直接回车执行，不用再点一下；
  ⌘R 历史搜索的插入同一姿态
- **托盘菜单在主窗隐藏时点击无效**：收进托盘后，托盘菜单点击「新建主机 /
  命令面板 / 设置」等项目会把界面弹在隐藏的主窗里。现在点击这些项目会
  先把主窗带回前台再执行
- **Otty 球菜单点外部收不起**：主窗口空白区域是窗口拖拽面，点击被系统
  拦截做拖拽。现在菜单展开时点击任意空白区域都会收起
- **Otty 球在深色主题下看不清**：改为应用图标同构小样（teal 渐变底盘 +
  白水线），任何主题下都清晰可辨
- **锁屏画面更协调**：「Ottr 已锁定」移到小水獭趴着的门沿上（作为门牌）；
  小水獭配色同步新标识
- **图标轨精简**：移除依赖已连接会话的文件图标哑钮（文件管理保留在连接
  会话后的视图切换里）

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
