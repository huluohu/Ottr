## 🛠 1.0.1：体验修正

v1.0.0 上线后收到的第一批反馈，全是"用起来硌手"的小问题——每个都修了。

### 🐞 问题修复

- **托盘菜单在主窗隐藏时点击无效**：收进托盘后，托盘菜单里只有「显示主窗口 / 退出」有效，
  其余项目（新建主机 / 命令面板 / 通知中心 / 检查更新 / 设置）看起来毫无反应——
  实际是弹在了隐藏的主窗里。现在点击这些项目会先把主窗带回前台再执行。
- **Otty 球菜单点外部收不起**：主窗口的空白区域是窗口拖拽面，点击被系统
  拦截做拖拽，菜单的"点外部关闭"因此失效。现在菜单展开时点击任意空白区域都会收起。
- **图标轨的文件图标像个哑钮**：文件浏览依赖已连接的会话，未连接时该图标
  无法点击也不说明原因。按反馈移除——文件管理入口保留在连接会话后的
  「终端 / 文件 / 进程」视图切换里，不再重复出现。
- **Otty 球在深色主题下看不清**：深色主题（深河 / 深渊 / 夜光河 / 雨窗）下
  墨色的水獭脸与侧栏底色几乎融为一体。改为应用图标同构小样——teal 渐变
  底盘 + 白水线，任何主题下都清晰可辨。
- **AI 生成命令：插入后不用再点一下**：命令插入终端后自动切回终端视图
  （文件 / 进程页签下同样生效）并把光标交还终端——直接回车即可执行。
  ⌘R 历史搜索的插入同一姿态。
- **锁屏画面更协调**：「Ottr 已锁定」移到小水獭趴着的门沿上（作为门牌）；
  小水獭配色同步新标识——墨色身躯替换旧版棕毛，胡须移除。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
