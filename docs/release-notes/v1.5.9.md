## 🔔 1.5.9：更新提醒全面整理

- **更新提醒只在一处**：自动检查到新版本时，只在左侧图标轨的锁定按钮上方
  亮起更新按钮（琥珀色呼吸点），不再同时弹出右下角提示；右下角提示只在
  你主动点「检查更新」时出现。
- **更新按钮贯穿全程**：有新版本、下载中（按钮上显示进度环）、安装完成
  待重启（青绿色呼吸点）、下载失败（红色点）四种状态一目了然；无论从
  哪里发起下载，进度都能在这里看到，不再出现下载一开始按钮就消失的情况。
- **点击弹出新版本面板**：显示新版本号、当前版本、发布日期与发布说明，
  可直接「下载并安装」；安装完成后在面板内「立即重启」；下载失败可
  「重试」；另有「在 GitHub 查看」直达该版本的发布页。
- **发布说明随更新清单下发**：装上本版本后，之后每次检查到新版本，都能
  在面板里直接阅读该版本的发布说明。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
