## 🌐 1.5.18：新增四种界面语言 + README 配图换成本语言 + 分屏关闭按钮不再乱入

- **界面新增四种语言**：日本語、한국어、Español、Italiano，与简体中文、繁體中文、文言、English 并列。界面、设置页、原生菜单、托盘菜单全部跟随；系统语言是这四种之一时，首次启动即自动切到对应语言，也可在设置页随时改。
- **README 配图换成各自语言的界面**：此前六种语言的 README 共用同一批中文界面截图，英文读者看到的是中文界面。现在每种语言的 README 都配自己语言的实拍界面图。
- **没分屏时终端右上角不再多出一个关闭按钮**：那个按钮是「关闭这一块分屏窗格」用的，只在真的分屏之后才出现；未分屏时它与页签上的 × 重复，容易误触。关闭整个会话仍用页签上的 ×。
- **原生菜单补齐四种语言**：macOS 应用菜单与托盘菜单此前只有中英两种，界面切到新语言时菜单还是英文，现在一并跟随。

## 📦 平台提示

- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」；便携版
  （zip 解压即用）不提供应用内自动更新，升级请下载新版 zip 解压覆盖。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
