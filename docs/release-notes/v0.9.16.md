## 🚀 更新内容

### ✨ 总览成为打开后的首页
- 打开 Ottr 直接进入「总览」：全部主机的状态与资源指标一眼看全
  （空库仍显示欢迎引导；上次退出时有会话标签则照常落在终端）
- 控制中心（左下快捷菜单）新增「总览」入口，排在第一位
- 工具菜单里的「多主机总览」更名为「总览」，与命令面板、控制中心同词
- 从主机树、命令面板发起连接时自动回到终端，不会被留在总览页

### 🛠 界面修复
- 设置页滚动条不再遮挡开关与按钮：内容右侧留出间距，设置面板与工具
  弹窗统一为轻量细滚动条
- macOS 菜单栏「视图 → 主题」：「跟随系统」移到第一位，与侧栏快切、
  设置页主题网格顺序一致
- MCP 设置：接入配置不再绑定 Claude Desktop——「客户端接入配置」给出
  任意 MCP 客户端（Claude Desktop、Cursor 等）通用的 mcpServers 写法，
  Claude Desktop 只是示例之一
- 监控面板空态会说明用法：未连接主机时直接告知前置条件（先连接主机、
  在主机表单或总览页开启监控），面板底部常驻采样说明（只读采样、
  默认每 5 秒、远端仅支持 Linux）——不再只显示「等待采样…」
- 插件面板开头说明插件形态（卡片 + 快捷命令，当前为内置示例）；
  网络摘要卡片空态写明前置条件

## 📦 平台提示
- macOS：本版本未使用 Apple 开发者签名。首次打开如提示「已损坏，无法打开」，在终端执行 `xattr -cr /Applications/Ottr.app`；
  连接局域网主机如提示 No route to host 或要求本地网络授权，见 README「macOS 提示已损坏或连不上局域网主机」一节。
- Windows：安装时如遇 SmartScreen 拦截，点「更多信息 → 仍要运行」。
- Linux：AppImage 需 `chmod +x` 后运行；deb/rpm 按发行版安装。
